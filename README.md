# James Cahours Portfolio

Personal portfolio website for [jamescahours.com](https://jamescahours.com).

## Stack

- Next.js
- React
- TypeScript
- Vercel-ready

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
